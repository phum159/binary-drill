# ฝึกโจทย์เลขฐาน (Binary Number Drill)

เว็บฝึกโจทย์แปลงเลขฐาน บวก ลบ คูณ หารเลขฐานสอง สำหรับวิชา Computer Architecture and Organization

🔗 **ใช้งานได้ที่:** https://ชื่อผู้ใช้.github.io/binary-drill/

## ฟีเจอร์

- โจทย์สุ่มไม่จำกัด 6 ประเภท:
  1. แปลงฐานสิบ → ฐานสอง
  2. แปลงฐานสอง → ฐานสิบ
  3. แปลงเป็น two's complement 16 บิต (signed short int)
  4. ลบเลขตามหลักการ ALU
  5. คูณเลขฐานสอง
  6. หารเลขฐานสอง
- ข้อ 4–6 ตอบได้ทั้งเลขฐานสองและเลขฐานสิบ ตรวจแยกทีละช่อง
- ตอบผิดจะโชว์วิธีทำแบบละเอียดทุกขั้นตอน (ไม่ใช่แค่เฉลยคำตอบ)
- มีปุ่มใบ้ก่อนดูเฉลย
- สรุปสถิติ: ทำไปกี่ข้อ ถูก/ผิดเท่าไหร่ ประเภทไหนพลาดบ่อยสุด
- ตารางค่าประจำหลัก (place value) และ Value Box สำหรับอ่านเลขลบ ไว้เป็นตัวช่วยตลอดหน้า

## การใช้งาน

เปิดลิงก์ด้านบนได้จากเบราว์เซอร์ทุกเครื่อง (คอม มือถือ แท็บเล็ต) ไม่ต้องติดตั้งอะไร

บน iPad/มือถือ: กด **Share > Add to Home Screen** เพื่อใช้งานเหมือนแอป

## รันเอง / แก้ไข

ไฟล์ `index.html` เป็น HTML + CSS + JavaScript ไฟล์เดียว ไม่มี dependency ภายนอก ไม่มี backend — ดาวน์โหลดแล้วเปิดด้วยเบราว์เซอร์ได้เลย

```bash
git clone https://github.com/ชื่อผู้ใช้/binary-drill.git
open binary-drill/index.html
```
